# 匿名化した波形解析結果

解析用の録音、原資料、そのパス、受信地点、RF周波数、時刻情報はコミットしない。
以下は音声波形から算出した数値のみ。原データは変更していない。

## 短時間トーン検査

音声形式は16,000 Hz、16-bit、mono、960,000標本、60秒。
DCを除去し40 msのHann窓を掛け、1,400〜1,600 Hzを25 Hz刻みのGoertzelで調査した。
最大のトーン成分と窓後の全エネルギーの比を `2 * Pmax / (N * sum(xw^2))` で比較した。
この比は窓の影響を含み、厳密なトーン電力比やSNRではない。

- 比の最小/中央値/最大: 0.0059 / 0.0290 / 0.1299。
- 1,500 Hzが最大だった区間: 1,499区間中679区間。
- 比が0.15以上だった区間: 0。
- ループ終端条件により最後の40 msはこの調査に含めていない。

強い純音を前提とする固定の電力比判定では、この波形を取り逃す。
近傍雑音に対するトーン突出度、継続性、調整可能な感度を検討する。
通話開始終了の正解ラベルがないため、誤ミュート率や通話の保全率を確定する資料にはしない。
新規検出器の評価は実装後に別途記録する。
